# OmicsPlorer 복합 질의 평가 사전 동결 기록 v1

## 동결 정보

- 동결 식별자: `omicsplorer-complex-query-prespec-v1`
- 동결 시각: `2026-09-02T19:55:15+09:00`
- 질의·조건 검토자: Hojin Lee
- 상태: 60개 질의와 기대 조건 검토 완료, 실제 비교 결과 수집 전
- 무결성 기록: 같은 폴더의 `SHA256SUMS`
- Git 기록: 이 파일들을 포함하는 동결 커밋과 이후 병합 커밋으로 확인

## 동결 범위

- 전체 질의: 60개
- 난이도: simple 20개, medium 20개, complex 20개
- 원문 작성 언어: 한국어
- 영어 질의: 공통 GEO 비교의 주 평가 입력
- 한국어 질의: OmicsPlorer 다국어 보조 평가 입력
- 기대 조건: 질병·상태, 조직, 세포 유형, 생물종, 분석법, 연구 설계, 비교군, 시점·처치·용량 및 제외 조건
- 알려진 정답 GSE: 사전 지정 0개
- 관련성 판정표: 형식만 준비되었고 판정 결과는 아직 없음

## 작성·검토 경위

질의 60개는 Hojin Lee가 작성하고 양 언어의 의미와 주제·설계 일치 여부를 검토했다. 기대 조건은 질의 문장만 바탕으로 AI 보조 초안을 만든 뒤 Hojin Lee가 한국어 통합 검토표에서 60개를 모두 확인하고 승인했다.

동결 전 최소 가용성 검사에서는 GEO 제한 API가 후보를 반환하는지만 확인했다. 후보의 제목, accession, 순위와 관련성은 질의 또는 기대 조건을 정하는 근거로 사용하지 않았다. 알려진 정답 accession은 근거 없이 만들지 않고 비워 두었다.

## 동결 후 변경 규칙

이 동결 이후에는 실제 검색 결과에 맞추어 질의, 난이도 또는 기대 조건을 수정하지 않는다. 오류가 발견되어 변경이 불가피하면 다음을 모두 기록한다.

1. 원래 값과 변경 값
2. 변경 이유와 시각
3. 결과를 본 뒤 발생한 변경인지 여부
4. confirmatory 결과에서 제외할지 또는 exploratory 분석으로 분리할지

동결된 주 평가 결과와 변경 후 탐색적 결과는 섞지 않는다.
