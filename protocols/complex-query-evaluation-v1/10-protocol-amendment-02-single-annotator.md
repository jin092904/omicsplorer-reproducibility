# Protocol amendment 02: 단일 관련성 판정자

결정일: 2026-09-02

판정자: Hojin Lee

적용 대상: `omicsplorer-complex-query-prespec-v1` 질의와 2026-09-02 confirmatory 수집 결과

결정 시점: 외부 서비스 응답 수집 완료 후, 후보 제목·accession의 사람 검토 및 관련성 채점 전

## 결정 내용

복합 질의 평가 v1의 사람 관련성 판정은 Hojin Lee 한 명이 수행한다. 논문과 공개 자료에는 `single-annotator blinded relevance assessment`로 보고하며, 두 사람의 독립 판정, 외부 독립 평가, 판정자 간 일치도 또는 합의 판정이라고 표현하지 않는다.

질의 작성자와 관련성 판정자가 동일하므로 연구 질문에 대한 사전 지식과 기대가 판정에 영향을 줄 수 있다. 시스템명과 순위를 숨겨 위험을 줄이되, 이를 완전한 독립성으로 해석하지 않는다.

## 결정 전 열람 범위

이 결정 전에 세 서비스의 응답 수집은 완료되었다. 자동 무결성 검사로 다음 집계만 확인했다.

- 서비스별 성공·실패 수
- 결과 0건인 질의 수
- API 벽시계 시간 분포
- 질의별 합집합 후보 수와 서비스 간 accession 중복 개수

후보의 제목, 설명, accession, 원래 순위와 개별 관련성은 사람이 열람하거나 채점하지 않았다. 따라서 판정 규칙은 개별 후보의 내용이나 유불리를 본 뒤 정하지 않았다.

## 판정자에게 보여주는 정보

- 한국어 및 영어 질의
- 질의별 사전 고정 필수·제외 조건
- 무작위 후보 코드
- 후보 제목과 설명
- 생물종, 분석법, 공개일과 표본 수
- 원본 GEO record 링크

## 숨기는 정보

- 후보를 반환한 시스템
- 각 시스템의 원래 순위와 점수
- 동일 후보를 반환한 시스템 수
- 서비스별 결과 0건 여부
- 시스템 간 비교 지표와 승패

판정자는 원본 GEO 링크로 공개 metadata를 확인할 수 있지만, 후보 accession을 OmicsPlorer·NCBI·OmicsDI에서 다시 검색해 반환 시스템을 추정하지 않는다.

## 판정 순서와 세션

- 질의 순서와 질의 안 후보 순서는 고정 seed `20260902`와 비공개 salt로 무작위화한다.
- 첫 판정표와 숨김 key의 SHA-256을 채점 전에 고정한다.
- 한 세션에서 최대 100개의 질의-후보 쌍을 판정한다.
- 세션 시작·종료 시각과 완료 행 범위를 기록한다.
- 시스템 정보를 공개하기 전 모든 첫 판정을 고정한다.

## 관련성 등급

- `3`: 필수 조건과 핵심 연구 설계를 명확히 모두 만족
- `2`: 주요 조건 대부분을 만족해 실제 검토 후보로 유용
- `1`: 주제 일부만 관련되고 핵심 조건 또는 설계가 부족
- `0`: 무관하거나 제외 조건을 위반하거나, 제공된 공개 metadata만으로 관련성을 지지할 근거가 없음

각 필수 조건은 `1`(충족), `0`(불충족), `NA`(그 질의에서 요구하지 않음)로 기록한다. 공개 metadata가 부족한 경우 `insufficient_evidence=yes`로 표시하고, 확인되지 않은 조건을 임의로 충족으로 처리하지 않는다.

관련성 `2` 이상을 관련 후보로 정의한다. 첫 번째 판정값을 주 분석에 사용하며 시스템 공개 후 점수를 유리하게 수정하지 않는다.

## 단일 판정자 일관성 검사

첫 판정 완료 후 739개 질의-후보 쌍의 10%인 74개를 고정 seed로 표본추출한다. 최소 7일의 간격을 둔 뒤 시스템 정보를 계속 숨긴 상태에서 다시 판정한다.

- 첫 판정값은 주 분석 값으로 유지
- 두 번째 판정값으로 첫 값을 대체하지 않음
- exact agreement와 quadratic weighted Cohen's kappa를 판정자 내 반복 일치도로 보고
- 이를 판정자 간 일치도나 외부 검증으로 표현하지 않음

재판정을 완료하지 못하면 해당 분석을 생략하고 계획 미완료 사실을 기록한다.

## 오류 수정 규칙

시스템 정보를 공개하기 전 명백한 입력 실수를 발견하면 원래 값, 수정 값, 이유와 시각을 변경 로그에 남긴다. 해석이 달라져 생긴 단순 의견 변경은 첫 판정 고정 후 수정하지 않는다. 시스템 공개 후 변경은 주 분석에 반영하지 않고 별도 민감도 기록으로만 남긴다.

## 통계·보고 영향

- inter-rater agreement와 adjudication 결과를 보고하지 않음
- 판정자 내 재검사 결과는 보조 품질 지표로만 보고
- 질의별 paired 지표와 bootstrap 신뢰구간을 유지
- 단일 개발자·질의 작성자·판정자가 동일하다는 한계를 명시
- 전체 생물정보학 연구자의 판단을 대표한다고 주장하지 않음

추후 두 번째 판정자가 참여하더라도 v1 결과를 본 뒤 추가된 평가는 별도 exploratory 또는 replication 분석으로 구분한다.
