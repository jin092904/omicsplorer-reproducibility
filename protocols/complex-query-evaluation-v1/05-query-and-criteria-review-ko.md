# 복합 질의와 필수 조건 한글 통합 검토표

작성일: 2026-09-02
상태: 이호진 최종 검토 완료

## 이 문서의 용도

이 문서는 `01-query-authoring-sheet.csv`의 한국어 질의와 `02-expected-criteria-sheet.csv`의 필수 조건을 한 화면에서 검토하기 위한 한글 보기다. 공식 평가 입력은 두 CSV이며, 이 문서만 수정하면 CSV에는 자동으로 반영되지 않는다. 수정할 내용은 검토 칸이나 별도 메모로 표시한 뒤 CSV에도 반영해야 한다.

- `필수 조건`은 검색 결과가 질의를 만족한다고 판정하기 위해 확인할 항목이다.
- 한 항목에 `·`로 연결된 값은 함께 요구되는 조건이다.
- `제외 조건`은 해당 결과가 포함하면 안 되는 조건이다.
- 표에 없는 생물종·조직·비교군 등은 그 질의에서 필수로 사전 지정하지 않은 것이다.
- `known relevant GSE`는 현재 60개 모두 비어 있다. 확실한 근거가 없으므로 임의의 정답 accession을 넣지 않았다.

검토 결과는 `확인`, `수정 필요` 또는 짧은 수정 메모로 남긴다.

## 검토 완료 후 처리

60행을 모두 확인한 뒤 수정 사항을 공식 CSV에 반영한다. 이후 `criteria_author`는 `Hojin Lee (reviewed AI-assisted draft)`로, `notes`는 사람 검토 완료를 나타내도록 바꾸고 다음 명령으로 최종 검증한다.

```bash
cd protocols/complex-query-evaluation-v1
python3 validate_workbook.py --final
```

최종 검사가 통과한 뒤에만 두 CSV의 Git commit과 SHA-256을 고정하고 실제 검색 결과 수집을 시작한다.
