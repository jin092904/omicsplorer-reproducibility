# Hard-query internal regression set

This directory contains 49 paired English/Korean queries and author-defined facet expectations.
It was designed to exercise negation, abbreviations, and compound study-design constraints.

The set is an internal regression fixture. It was not sampled from a documented user population,
and the facet expectations are not an independently adjudicated relevance ground truth. Metrics
computed from it must therefore be labeled internal or exploratory and reported with the query
count, language, retrieval configuration, corpus cut-off, and limitations.
