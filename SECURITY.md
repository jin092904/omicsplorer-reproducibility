# Security

Do not report vulnerabilities in the proprietary OmicsPlorer service through a public issue.
Until a project security address is published, contact the corresponding author through the
address listed in the paper. Do not include credentials, personal data, or exploitable details
in a public report.

This repository intentionally contains no production credentials. `.env.example` contains
placeholders only. Raw external-service responses and authenticated browser traces are outside
the public artifact boundary.
